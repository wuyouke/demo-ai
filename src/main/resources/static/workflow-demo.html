🎯 核心功能

📋 任务节点

调用注册的工具执行具体操作，如查询数据、处理信息等。

◇ 决策节点

根据条件判断选择不同的执行路径，支持多种操作符。

🔁 循环节点

遍历集合中的每个元素，反复执行同一个操作。

🔄 重试节点

失败时自动重试，支持指数退避策略和最大重试次数。

⏳ 等待节点

暂停工作流执行指定时间，用于定时任务。

⚡ 并行节点

同时执行多个节点，充分利用并发能力提升效率。

📖 API 文档

创建工作流
POST /api/workflows/create { "name": "订单处理", "description": "完整的订单处理工作流" } 返回: { "success": true, "workflowId": "uuid", "name": "订单处理" }
添加节点
POST /api/workflows/{workflowId}/nodes { "name": "查询库存", "type": "TASK", "config": { "toolName": "inventory", "params": {"sku": "ABC123"} } }
连接节点
POST /api/workflows/{workflowId}/connect { "fromNodeId": "node1", "toNodeId": "node2" }
执行工作流
POST /api/workflows/{workflowId}/execute 返回: { "success": true, "status": "RUNNING" }
查询状态
GET /api/workflows/{workflowId}/status 返回: { "success": true, "status": "COMPLETED", "nodeCount": 5, "nodes": {...} }

📚 使用指南

节点类型 主要用途 配置参数 后续连接
START 工作流入口 无 连接到下一个节点
END 工作流出口 无 结束点，无后续
TASK 调用工具 toolName, params 连接到下一个节点
DECISION 条件分支 conditions, defaultNextNodeId 多个不同路径
LOOP 循环迭代 collection, itemVar, bodyNodeId 连接到下一个节点
RETRY 失败重试 maxRetries, delayMs, backoffMultiplier 连接到下一个节点
WAIT 延迟等待 delayMs 连接到下一个节点
PARALLEL 并发执行 nodeIds 连接到下一个节点
